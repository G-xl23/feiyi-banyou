## 三、运行前自查表

- [ ] `cd server && npm install --omit=dev` 无报错
- [ ] `.env` 已按需配置（或留空以离线模板模式运行）
- [ ] `npm start` 后访问 `http://localhost:3000` 页面正常、右上角显示"系统就绪 · 知识库 3 城 / 23 区县 · 非遗 39 项 · 8 个智能体"
- [ ] `node scripts/validate-data.js` 输出数据完整性校验通过
- [ ] `node scripts/smoke-test.js` 输出 `42/42 通过`
- [ ] 行程规划页可生成含"非遗联动景点"红色标签的行程；线路模式选"乡村深度"可生成含"乡村文旅点位"标签、村宿建议与乡村好物的行程
- [ ] 非遗知识库页命中知识库时显示"本地知识库直答"，未收录问题显示"暂未收录"
- [ ] 乡村产业赋能页选择工坊后可生成六件套方案（定位/定价/电商文案/短视频/包装/对策）
- [ ] 乡村振兴看板显示 HLI 指数排行、增收测算与统计卡；修改游客量后"重新测算"数字联动更新；切换城市/区县后指标按新口径刷新
- [ ] 顶栏切到"地方工作人员"：智能对话页可问答、可"一键生成总结材料"并复制；看板与对话体口径一致
- [ ] 智能对话页提问后可见"多智能体协作链路"逐步点亮
- [ ] AIGC 页可生成内容且显示"生成方式"标注
- [ ] 各页面"复制"按钮可用（`localhost` 或 HTTPS 环境下剪贴板 API 才可用）

## 四、提交前须补齐的三件事

1. **三张核心功能截图**：已截取 15 张真实运行截图存于 `docs/screenshots/`（含工作人员对话体、看板地区下钻、苏州区县口径），可在运行环境按《作品简介》末尾指引重截替换。
