## 二、数据整理原则

1. **只收录可溯源的公开资料**。所有非遗项目、级别、批次、传承人均来自上述官方公开渠道；不采用商业旅游平台的二次加工描述作为事实依据。
2. **事实与表达分离**。事实字段（名称/类别/级别/传承人/地点/时间）由人工录入；描述性文字（简介、故事）由团队撰写，并在需要时由大模型润色，润色过程禁止引入新事实。
3. **不确定信息显式标注**，避免误导：
   - 传承人条目多附"（以中国非遗网传承人名录为准）"；
   - 开放时间统一表述为"以现场公告为准""以当月排期公告为准"；
   - 未取得明确官方公布信息者不标注具体批次年份，仅标注级别，例如"省级非物质文化遗产（以官方名录为准）"。
4. **宁缺毋滥**。对无法核实的项目（例如未查到公开名单确认的市级项目）不写入知识库；知识库未收录的问题，系统会明确回答"本地知识库暂未收录"，而不会编造。
5. **可追责**。每条非遗数据均隶属于具体城市与项目 ID，便于后续逐条复核与更新（见 `server/src/data/heritage.js`）。

## 五、免责与更新机制

1. 本系统面向文旅导览与非遗科普，所有信息**不构成官方发布**；出行前请以景区、场馆官方公告为准。
2. 非遗名录与传承人信息存在滚动更新可能，系统采取"数据与代码分离"设计：更新数据只需修改 `server/src/data/heritage.js` 中对应条目，无需改动任何智能体逻辑。
3. 若发现数据错误，可通过项目 README 中的联系方式反馈，团队将核对官方来源后修正。
