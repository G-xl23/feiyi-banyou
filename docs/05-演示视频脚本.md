# 演示视频脚本（MP4，时长 ≤ 5 分钟，文件 ≤ 150MB）

> 说明：屏幕录制需在本地运行环境完成（录屏软件：OBS Studio / Windows 自带 Xbox Game Bar / 剪映录屏均可）。
> 本脚本提供**逐秒分镜、解说词、操作步骤**，按稿录制一次即可成型；录制后请用剪映或 HandBrake 压制为 1080p / 30fps / H.264，控制码率在 4 Mbps 以内以确保体积 ≤150MB。

## 一、录制前准备（约 5 分钟）

1. 启动系统：进入 `server` 目录，配置好 `.env`（建议接入大模型以获得更生动的 AIGC 效果；无 Key 时演示"离线模板模式"同样完整，可在视频中作为亮点说明）。
2. 执行 `npm start`，浏览器打开 `http://localhost:3000`，确认右上角状态显示"系统就绪 · 知识库 2 城"。
3. 浏览器窗口设为 1920×1080，缩放 100%，关闭无关标签页与通知；开启演示用的"鼠标点击高亮"（如 Windows 的 PowerToys 或录屏软件自带光标高亮）。
4. 提前把要演示的输入内容复制到剪贴板备用，避免现场打字卡顿。

## 三、录制与压制注意事项

1. **一次录完主流程**，字幕与解说可在剪映中后期添加，避免边操作边念稿导致节奏拖沓。
2. **鼠标移动放慢**，关键结果（红色非遗标签、来源标注、生成方式标注）停留 2 秒以上，便于评委看清。
3. **导出参数**：分辨率 1920×1080，帧率 30fps，H.264，码率 3-4 Mbps；4 分 45 秒视频体积约 65-95MB，满足 ≤150MB 要求。
4. **务必避免**：出现真实 API Key、服务器 IP 与管理后台等敏感信息（如录制时打开过 `.env` 文件，请剪掉该片段）。
5. 视频命名建议：`非遗伴游-演示视频-队伍名.mp4`。

## 四、现场答辩补充（非视频内容，供决赛现场展示使用）

- **亮点话术**：①三端闭环——非遗从"被保护"到"能造血"，直接回应乡村振兴与产业赋能；②行程与非遗深度绑定而非模块拼接；③可解释量化指标（HLI 公式与增收测算参数全部暴露，拒绝黑盒）；④多智能体协作链路可视化（SSE 实时推送）；⑤面向严肃文化内容的幻觉抑制链；⑥无大模型也能完整运行的降级设计。
- **可现场演示的反差**：先问一个知识库未收录的问题，展示系统"不编造"；再问一个已收录问题，展示知识库直答与来源标注；问"乡村振兴的运营数据怎么样"，展示调度器把请求路由给洞察 Agent 并在看板页展开。
- **可现场扩展**：说明新增城市只需追加一条城市数据（数据驱动、无需改代码），体现落地复制能力。
- **数据来源答疑**：如评委追问数据真实性，打开《非遗数据来源说明》文档——乡村点位与统计数据均来自潮安区人民政府门户网站、泉州市文旅局等公开渠道，逐条可溯源。
