# 作品简介（800 字以内）

## 非遗伴游——基于多智能体的非遗活态传承与乡村产业赋能平台

**痛点**：主流行程工具只会排景点、订酒店，游客到了古城只看到建筑与风景，看不到背后的手艺与民俗；乡村非遗工坊普遍"手艺好、卖不好"——定价缺依据、电商内容能力弱、体验客流变不成订单；基层文旅部门则缺少低成本、可解释的量化工具来判断"该扶哪个项目、投入能带来多少增收"。非遗要活态传承，先要能造血。

**作品是什么**：本作品是一套**三端闭环**的多智能体 Web 应用，七个智能体在原创调度器下分工协作。**游客端**（旅行规划、景点-非遗讲解、美食民俗、非遗知识库、AIGC 文创五个 Agent）：行程自动嵌入非遗展馆、手作体验与**乡村振兴示范村、非遗工坊、农事体验点**，支持城市经典/城乡融合/乡村深度三种线路模式；可查非遗技艺与传承人，一键生成非遗故事、宣传文案与文创构思。**工坊端**（乡村产业赋能 Agent）：选择工坊即可生成产品定位、三档定价建议、电商详情页文案、30 秒短视频脚本、包装升级与渠道对策，打通"体验引流→产地直邮"产销闭环。**政府端**（乡村振兴运营洞察 Agent）：非遗活态传承指数（HLI）、三档增收测算、濒危预警与工坊对策，指标算法全部可解释、可复现。

**核心创新**：

1. **三端闭环，非遗从"被保护"到"能造血"**。游客行程为工坊导流，工坊方案供政府施策，政府看板反哺线路调配——直接回应乡村振兴与产业赋能命题。
2. **非遗与行程深度绑定，而非简单拼接**。数据层建立"景点↔非遗↔乡村工坊"关联，规划智能体以原创评分算法排序，非遗与乡村点位随人群与模式动态进入行程。
3. **多智能体协作链路可视化**。调度过程经 SSE 流式推送，前端实时点亮"意图识别→Agent 分派→处理耗时"，让"多智能体"看得见。
4. **面向严肃文化内容的幻觉抑制链**。命中知识库则按意图组卷直答；未命中时明确回答"暂未收录"，事实性信息标注来源与不确定性，杜绝 AI 编造非遗。
5. **数据驱动的多城市扩展机制（v3.0）**。城市注册、区县归属、别名识别全部下沉数据层，新增城市只需填四张数据表，八个智能体与全部界面自动跟随；看板与对话体共用"城市→区县"两级口径，区县无工坊明细时显式标注"回落"，杜绝口径混淆。

**社会价值与前景**：作品让非遗从"名录"走向"行程与订单"，让乡村手艺获得 AI 时代的经营能力，让政府决策有据可依，契合大赛"人工智能赋能应用创新、发展新质生产力"主题。系统纯软件实现，知识库数据驱动，新增城市只需追加数据文件，具备向其他非遗富集地区快速复制的潜力。

**运行与部署**：仅依赖 Node.js 与一个 Web 框架，已部署公网；不接入大模型时以离线模板模式完整运行，保证演示稳定。
