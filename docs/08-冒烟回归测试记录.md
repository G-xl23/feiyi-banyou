## 一、执行方式

```bash

cd server && npm start

# 2) 运行冒烟回归
node scripts/smoke-test.js
```

脚本每项用例独立建连（禁用连接复用）并设置 180 秒超时，以适配大模型 10~30 秒级的应答耗时；
传输层偶发错误自动重试 2 次，HTTP 状态码类错误不做重试，确保判定严格。

## 三、覆盖范围说明

1. **基础可用性**：健康检查与就绪检查，确认 3 城 / 23 区县 / 8 智能体 / 双受众全部就位，且运行模式正确上报为大模型模式。
2. **游客侧五个智能体**：行程规划（城市经典 / 城乡融合 / 乡村深度三种线路模式，含苏州）、景点-非遗讲解（潮州广济桥、苏州网师园）、美食民俗、非遗知识问答、AIGC 文创生成。
3. **工作人员侧（工坊端 + 政府端）**：工坊清单、工坊赋能方案（六件套，含苏州镇湖苏绣）、乡村振兴运营洞察看板（全市口径 + 区县下钻 + 非遗有/工坊无的回落口径）。
4. **政务智能对话体**：总结归纳（全域 / 区县下钻 / 按关注重点排序）、濒危预警问答、增收测算口径、跨城市横向对比、工坊经营建议、无明确意图时的兜底引导。
5. **调度器与协作链路**：自然语言意图路由（含数据驱动的城市识别）、游客与工作人员两类受众分流、SSE 协作链路事件序列完整性（dispatch-start → intent → agent-start → agent-done → final）。
6. **异常与边界**：非法城市、非法区县、非法工坊、非法生成类型、空问题、空提问共 7 项，全部返回 400 与规范化中文错误信息。

## 四、大模型接入相关的重点验证

| 验证点 | 期望行为 | 实测结果 |
| --- | --- | --- |
| 通用问题由大模型直接回答 | 不因知识库未收录而拒答，由大模型依自身知识作答 | 通过 |
| 非遗事实以知识库为准 | 级别、年份、传承人、统计数字命中知识库时按库内数据直答 | 通过 |
| 幻觉抑制 | 知识库未收录且不宜推测的事实的，明示"暂未收录"，不编造 | 通过 |
| 模型标注 | 大模型生成的回答自动附模型名称与版本 | 通过（deepseek-v4-flash） |
| 结构化业务链路不受影响 | 行程、讲解、赋能方案、看板指标保持确定性算法输出 | 通过 |
